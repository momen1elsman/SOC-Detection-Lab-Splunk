# SOC Detection Lab - Splunk

## Overview

This lab simulates a real-world attack scenario and demonstrates how a SOC analyst can detect malicious activity using Splunk SIEM.

The exercise covered reconnaissance, brute-force attacks, log collection, event analysis, and detection logic creation.

---

## Lab Environment

- Kali Linux
- Nmap
- Hydra
- Splunk SIEM
- Target Machine

---

## Phase 1 - Reconnaissance

The attacker performed host discovery and service enumeration using Nmap.

### Objectives

- Identify active hosts
- Discover open ports
- Detect running services

---

## Phase 2 - Brute Force Attack

Hydra was used to perform an SSH brute-force attack against the target.

### Activities

- Password guessing
- Authentication attempts
- Credential discovery

---

## Phase 3 - Detection

Splunk collected and analyzed logs generated by the attack.

Detection focused on:

- Port scanning activity
- Multiple failed login attempts
- Successful login after brute force attempts

---

## SPL Queries

### Brute Force Detection

```spl
sourcetype=linux_secure "Failed password"
| stats count by src_ip, user
| where count > 10
```

### Port Scan Detection

```spl
sourcetype=ids OR firewall
| stats dc(dest_port) as unique_ports by src_ip
| where unique_ports > 15
```
